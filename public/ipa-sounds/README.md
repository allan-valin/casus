# IPA sample sounds

Recordings of single IPA sounds from Wikimedia Commons, as linked from Wikipedia's "IPA consonant chart with audio"
and "IPA vowel chart with audio" (fetched 2026-10-20). Only files under CC0, public domain, CC BY or CC BY-SA were
kept; `index.json` maps each symbol to its file (`f`), the Commons file name (`file`), its licence and author.
Re-encoded to mono 32 kbps MP3. The Commons page of each file is https://commons.wikimedia.org/wiki/File:<file>.
