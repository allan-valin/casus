# English in Casus

Added 2026-10-20 on Casus World, taught to Brazilians (lessons with Portuguese explanations; exercises translate to
Portuguese, from Tatoeba's eng–por links).

- Roles: English marks case only on pronouns (I / me, he / him, we / us, they / them): those come from the closed-class
  table by form; the rest from word order — before the verb the subject, the first bare noun phrase after it the
  direct object, to + noun phrase after it the indirect object (src/lang/en/stages.js, on the shared Romance rules).
- Not yet: the double object without to (gave John the book), to + a place read as indirect object, her (object or
  possessive) left to the dictionary.
- Data: English Wiktionary via kaikki (CC BY-SA), kept for the 50,000 commonest English subtitle words: 116,193 of
  1,492,836 entries. Voice: eSpeak NG en-us; Piper en_US-lessac-medium.
