# Spanish in Casus

Added 2026-10-20 on the generic builder, caseless, on the Romance role rules shared with Portuguese and French.

- Roles: subject before the verb; the first bare noun phrase after it the direct object; a / al / para + noun phrase
  after it the indirect object; lo / la / los / las before a verb direct object pronouns, le / les indirect.
- Not yet: the "personal a" before a person who is the direct object (Veo a Juan) is read as an indirect object.
- Data: English Wiktionary via kaikki (CC BY-SA), kept for the 50,000 commonest Spanish subtitle words: 59,608 of
  811,049 entries. Voice: eSpeak NG es; Piper es_ES-davefx-medium.
