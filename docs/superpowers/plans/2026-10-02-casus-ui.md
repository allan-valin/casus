# Casus UI (Two-Pane Reader) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Put the core parser on screen: a static Vite + Svelte page with the untouched text on the left and the same words as case-coloured, draggable, pinnable blocks on the right, with the dictionary popup, layer toggles, autosave and export the spec asks for — demoable in thirty seconds on a bundled passage.

**Architecture:** Svelte 5 owns rendering and drag events only. Every parse decision still comes from the framework-free modules in `src/lib/` (`createState`, `createLexicon`, `runCascade`); the UI adds a thin reactive store around `createState`, a handful of pure helper modules (colours, arrangement, chunks, era, persistence, export) that are unit-tested without a DOM, and components that are tested thinly. Data is fetched from same-origin static files (`/data/...`) built by `tools/build_index.py`; nothing heavy runs in the request path.

**Tech Stack:** Node 20+, Vite 8, Svelte 5 (runes), `@sveltejs/vite-plugin-svelte` 7, vitest 5 with `jsdom` and `@testing-library/svelte` 5 for the few component tests, `svelte-dnd-action` (MIT) or `sortablejs` (MIT) — Task 1 measures which. No other runtime dependency.

**Spec:** `docs/superpowers/specs/2026-08-20-casus-design.md` — this plan implements §6, §7, §8, §9, §10.1 and answers §12 question 2. The core plan (`docs/superpowers/plans/2026-08-20-casus-core.md`, branch `casus-core`) is the base: read its README "Current state" and `docs/DATA.md` first.

## Global Constraints

- **Open source only.** Every dependency must be public domain, MIT, Apache-2.0, BSD or CC BY-SA. No commercial or proprietary dependency, ever.
- **Parser modules are DOM-free.** `src/lib/*.js` may not import Svelte or touch `window`, `document`, `fetch`. The UI calls them; it never re-implements them.
- **Ambiguity is shown, never guessed (§4).** A block never displays a single case unless exactly one candidate survives. Ambiguous blocks render striped in every candidate hue with a `?` badge.
- **Colour is never the only channel (§7.1).** Every nominal block carries a two-letter case badge `Nm Gn Dt Ac Ab Vc Lc`; verbs carry `person·number tense` (`3sg pf`).
- **The original order is never lost (§7.6).** Every block keeps a superscript index; "restore original order" is one click.
- **No network at runtime beyond same-origin static assets.** The lexicon is read from `/data/manifest.json`, `/data/forms/<shard>.json`, `/data/lemmas.json`, `/data/glosses.en.json`, `/data/glosses.pt.json` (the last one may be absent — fall back to English with the badge flipped, §8).
- **The lexicon always gets the manifest** (`createLexicon({ fetchShard, manifest })`): without it the shard rule silently falls back to two letters and every lookup misses (core review, deferred minor 7).
- **Autosave to `localStorage`**, keyed by a hash of the text, debounced ~300 ms; `beforeunload` guard only while a write is pending (§9).
- **Bundled passages are short, public-domain, with source and edition recorded in `public/samples/SOURCES.md` (§10.1).**
- **Portuguese glosses are CC BY-SA and stay a separate asset with their own notice; never blended into Whitaker-derived data.**
- **TDD.** Test first, watch it fail, implement minimally, watch it pass, commit. Pure helpers get full unit tests; components get thin tests of behaviour, not markup (§11).
- **Desktop two-pane layout; mobile-first is a non-goal (§2).**

## Review Focus

Input classes the spec implies and no task's tests exercise directly; each line's test is added to the owning task below.

1. **A passage with a word the lexicon does not know** (`Troiae`): the block must render as unknown (`!` badge, neutral colour), stay draggable, and the dictionary popup must say *not in lexicon* rather than crash on a missing lemma — Task 6 (`Block`), Task 8 (`Dictionary`).
2. **A sentence with no prepositions and no agreeing pairs** (every block ambiguous): nothing is glued, no connector shows, auto-sort groups by the *first* candidate's case and says so — Task 9 (`chunks`), Task 10 (`order`).
3. **`localStorage` unavailable or full** (private window, quota): the app must still load and parse; the save silently no-ops and the guard never fires — Task 12 (`persist`).
4. **A saved arrangement whose text no longer matches** (same hash prefix, different token count): restore must drop the stale order and pins instead of applying them to the wrong words — Task 12 (`persist.restore`), Task 5 (`createReader` drops an order whose length does not match).
5. **The user pins, then changes era or gloss language**: pins and arrangement survive a toggle that only re-renders — Task 5 (`reader` store), Task 14 (`Toolbar`).

`src/app/lib/fetchers.js`:
```js
async function getJSON(fetchImpl, url) {
  const res = await fetchImpl(url);
  if (!res.ok) throw new Error(`${url}: ${res.status}`);
  return res.json();
}

export function makeFetchShard(fetchImpl, base = '/data') {
  return (name) => getJSON(fetchImpl, `${base}/forms/${name}.json`);
}

export function loadManifest(fetchImpl, base = '/data') {
  return getJSON(fetchImpl, `${base}/manifest.json`);
}

export function loadLemmas(fetchImpl, base = '/data') {
  return getJSON(fetchImpl, `${base}/lemmas.json`);
}

/** null when the language has no file (Portuguese until Task 8 of the core plan is built). */
export async function loadGlosses(fetchImpl, base = '/data', lang = 'en') {
  try {
    return await getJSON(fetchImpl, `${base}/glosses.${lang}.json`);
  } catch {
    return null;
  }
}
```

`vite.config.js` — serves the repo's gitignored `data/` at `/data` in dev, and `npm run build` copies it next to the bundle:
```js
import { defineConfig } from 'vite';
import { svelte } from '@sveltejs/vite-plugin-svelte';
import { existsSync, createReadStream, cpSync } from 'node:fs';
import { join, resolve } from 'node:path';

const DATA = resolve('data');

function serveData() {
  return {
    name: 'casus-serve-data',
    configureServer(server) {
      server.middlewares.use('/data', (req, res, next) => {
        const file = join(DATA, decodeURIComponent(req.url.split('?')[0]));
        if (!file.startsWith(DATA) || !existsSync(file)) return next();
        res.setHeader('Content-Type', 'application/json');
        createReadStream(file).pipe(res);
      });
    },
    closeBundle() {
      if (existsSync(DATA)) cpSync(DATA, resolve('dist/data'), { recursive: true });
    },
  };
}

export default defineConfig({
  plugins: [svelte(), serveData()],
  test: {
    environment: 'node',
    environmentMatchGlobs: [['tests/components/**', 'jsdom']],
  },
});
```

```js
/** Hue = case, brightness = number (spec §7.1). Degrees on the HSL wheel, spread so neighbours differ. */
export const CASE_HUES = { nom: 210, gen: 30, dat: 270, acc: 0, abl: 120, voc: 330, loc: 60 };
export const VERB_HUE = 180;
export const FUNCTION_HUE = 0;
const NEUTRAL = 'hsl(0 0% 85%)';

const CASE_BADGE = { nom: 'Nm', gen: 'Gn', dat: 'Dt', acc: 'Ac', abl: 'Ab', voc: 'Vc', loc: 'Lc' };
const TENSE_BADGE = { pres: 'pr', impf: 'im', fut: 'fu', perf: 'pf', plup: 'pl', futp: 'fp' };
const NOMINAL = new Set(['noun', 'adj', 'pron', 'num', 'vpar', 'supine']);

export function family(analysis) {
  if (NOMINAL.has(analysis.pos)) return 'nominal';
  if (analysis.pos === 'verb') return 'verb';
  return 'function';
}

export function badge(analysis) {
  if (family(analysis) === 'nominal') return CASE_BADGE[analysis.case] ?? '—';
  if (analysis.pos === 'verb') {
    const tense = TENSE_BADGE[analysis.tense] ?? analysis.tense;
    if (analysis.mood === 'inf') return `inf ${tense}`;
    return `${analysis.person}${analysis.number} ${tense}`;
  }
  if (analysis.pos === 'prep') return 'Prp';
  return '—';
}

function hsl(hue, number) {
  const light = number === 'pl' ? 72 : 60;
  return hue === null ? NEUTRAL : `hsl(${hue} 70% ${light}%)`;
}

/** The hues a candidate paints with: one per case for nominals, one per governed case for a preposition. */
function hues(analysis) {
  switch (family(analysis)) {
    case 'nominal': return analysis.case in CASE_HUES ? [[CASE_HUES[analysis.case], analysis.number]] : [[null, 'sg']];
    case 'verb': return [[VERB_HUE, analysis.number === 'pl' ? 'pl' : 'sg']];
    default:
      if (analysis.pos === 'prep' && Array.isArray(analysis.governs) && analysis.governs.length) {
        return analysis.governs.map((c) => [CASE_HUES[c] ?? null, 'sg']);
      }
      return [[null, 'sg']];
  }
}

function stripes(colours) {
  const step = 8;
  const stops = colours.map((c, i) => `${c} ${i * step}px ${(i + 1) * step}px`).join(', ');
  return `repeating-linear-gradient(135deg, ${stops})`;
}

/**
 * blockStyle(block, layers) -> { background, badge, striped, unknown }
 * Ambiguity is shown, never guessed: more than one distinct hue means stripes and a `?`.
 */
export function blockStyle(block, layers) {
  if (block.candidates.length === 0) return { background: NEUTRAL, badge: '!', striped: false, unknown: true };
  const shown = block.candidates.filter((c) => layers[family(c.analysis)]);
  if (shown.length === 0) return { background: NEUTRAL, badge: '', striped: false, unknown: false };
  const colours = [...new Set(shown.flatMap((c) => hues(c.analysis)).map(([h, n]) => hsl(h, n)))];
  const badges = [...new Set(shown.map((c) => badge(c.analysis)))];
  if (colours.length === 1 && badges.length === 1) {
    return { background: colours[0], badge: badges[0], striped: false, unknown: false };
  }
  return { background: stripes(colours.length > 1 ? colours : [colours[0], NEUTRAL]), badge: '?', striped: true, unknown: false };
}
```

```js
export const ERAS = [
  { id: 'archaic', label: 'Archaic / early (to c. 80 BC)', ages: ['A', 'B'] },
  { id: 'classical', label: 'Classical (Cicero to Trajan)', ages: ['C'] },
  { id: 'late', label: 'Late (to c. 600)', ages: ['D', 'E'] },
  { id: 'medieval', label: 'Medieval', ages: ['F'] },
  { id: 'neo', label: 'Renaissance / Neo-Latin / modern', ages: ['G', 'H'] },
];

export const AGE_LABEL = {
  X: 'unknown', A: 'archaic', B: 'early', C: 'classical', D: 'late', E: 'later', F: 'medieval', G: 'neo-Latin', H: 'modern',
};

function indexOfAge(age) {
  return ERAS.findIndex((e) => e.ages.includes(age));
}

export function eraStatus(age, eraId) {
  const here = ERAS.findIndex((e) => e.id === eraId);
  const there = indexOfAge(age);
  if (there < 0 || here < 0) return 'unknown';
  const d = Math.abs(here - there);
  return d === 0 ? 'in' : d === 1 ? 'near' : 'out';
}

export function warning(age, eraId) {
  if (eraStatus(age, eraId) !== 'out') return null;
  const era = ERAS.find((e) => e.id === eraId);
  return `only attested as ${AGE_LABEL[age]}; the text is ${era.label.split(' (')[0].toLowerCase()}`;
}
```

```js
import { createState } from '../../lib/state.js';
import { initialOrder, move as moveIn, autoSort as autoSortIn } from '../lib/order.js';

const DEFAULT_LAYERS = { nominal: true, verb: true, function: true, classes: false };

/**
 * The single source of truth for the page (spec §5.2 state.js + the UI state).
 * Parse decisions come from createState; this adds layers, era, gloss language,
 * per-sentence arrangement and unglued chunks, and serialises all of it.
 */
export function createReader({ lexicon, text, saved = null }) {
  const state = createState({ text, lexicon, saved });
  let version = $state(0);                       // bumped after every state.* call so getters re-read
  let loaded = $state(false);
  const layers = $state({ ...DEFAULT_LAYERS, ...(saved?.layers ?? {}) });
  let era = $state(saved?.era ?? 'classical');
  let glossLang = $state(saved?.glossLang ?? 'en');
  const orders = $state(Object.fromEntries(Object.entries(saved?.order ?? {}).map(([k, v]) => [Number(k), [...v]])));
  const unglued = $state(new Set(saved?.unglued ?? []));

  function touch() { version += 1; }

  function currentBlocks() {
    void version;
    return loaded ? state.blocks() : [];
  }

  function currentOrder() {
    const i = state.selected();
    const blocks = currentBlocks();
    const stored = orders[i];
    const valid = stored && stored.length === blocks.length && stored.every((n) => blocks.some((b) => b.token.index === n));
    return valid ? stored : initialOrder(blocks);
  }

  return {
    get text() { return text; },
    get sentences() { void version; return state.sentences(); },
    get selected() { void version; return state.selected(); },
    get blocks() { return currentBlocks(); },
    get order() { return currentOrder(); },
    layers,
    get era() { return era; },
    set era(v) { era = v; },
    get glossLang() { return glossLang; },
    set glossLang(v) { glossLang = v; },
    get unglued() { return unglued; },

    async load() { await state.load(); loaded = true; touch(); },
    select(i) { state.select(i); touch(); },
    pin(tokenIndex, analysis) { state.pin(tokenIndex, analysis); touch(); },
    unpin(tokenIndex) { state.unpin(tokenIndex); touch(); },
    move(from, to) { orders[state.selected()] = moveIn(currentOrder(), from, to); touch(); },
    autoSort() { orders[state.selected()] = autoSortIn(currentOrder(), currentBlocks()); touch(); },
    restoreOrder() { delete orders[state.selected()]; touch(); },
    toggleGlue(prepIndex) { if (unglued.has(prepIndex)) unglued.delete(prepIndex); else unglued.add(prepIndex); touch(); },

    toJSON() {
      const base = state.toJSON();
      return {
        ...base,
        layers: { ...layers },
        era,
        glossLang,
        order: Object.fromEntries(Object.entries(orders).map(([k, v]) => [k, [...v]])),
        unglued: [...unglued],
      };
    },
  };
}
```

```js
export function describeAnalysis(a) {
```

```js
const GOVERNED_BY = /^government: governed by (\S+) /;
const AGREES_WITH = /^agreement: matches (\S+) /;

function reasonsOf(block) {
  return block.candidates.flatMap((c) => c.reasons);
}

/** preposition index -> object index, for adjacent pairs the cascade settled; unglued ones are skipped. */
export function gluePairs(blocks, unglued = new Set()) {
  const out = new Map();
  for (let i = 0; i < blocks.length - 1; i += 1) {
    const prep = blocks[i];
    const object = blocks[i + 1];
    if (unglued.has(prep.token.index)) continue;
    if (!prep.candidates.some((c) => c.analysis.pos === 'prep')) continue;
    const named = reasonsOf(object).map((r) => GOVERNED_BY.exec(r)?.[1]).filter(Boolean);
    if (named.includes(prep.token.surface)) out.set(prep.token.index, object.token.index);
  }
  return out;
}

/** token index -> token indices it agrees with, both directions, by surface name in the reason. */
export function partners(blocks) {
  const bySurface = new Map(blocks.map((b) => [b.token.surface, b.token.index]));
  const out = new Map();
  const link = (a, b) => {
    if (!out.has(a)) out.set(a, []);
    if (!out.get(a).includes(b)) out.get(a).push(b);
  };
  for (const block of blocks) {
    for (const r of reasonsOf(block)) {
      const target = AGREES_WITH.exec(r)?.[1];
      if (target && bySurface.has(target)) {
        link(block.token.index, bySurface.get(target));
        link(bySurface.get(target), block.token.index);
      }
    }
  }
  return out;
}

/** The pool's draggable items in display order; a glued pair sits where its preposition sits. */
export function items(blocks, order, glue) {
  const glued = new Set(glue.values());
  const out = [];
  for (const index of order) {
    if (glued.has(index)) continue;
    const object = glue.get(index);
    const indices = object === undefined ? [index] : [index, object];
    out.push({ id: indices.join('+'), indices });
  }
  return out;
}
```

```js
import { family } from './colors.js';

const CASE_ORDER = ['nom', 'voc', 'gen', 'dat', 'acc', 'abl', 'loc'];
const GROUP_RANK = Object.fromEntries([...CASE_ORDER, 'verb', 'function', 'unknown'].map((k, i) => [k, i]));

export function initialOrder(blocks) {
  return blocks.map((b) => b.token.index);
}

export function move(order, from, to) {
  const out = order.filter((n) => n !== from);
  out.splice(to, 0, from);
  return out;
}

/** What a block sorts by: its case when resolved, '?' + the first candidate's case when not. */
export function sortKey(block) {
  if (block.candidates.length === 0) return 'unknown';
  const first = block.candidates[0].analysis;
  const fam = family(first);
  if (fam !== 'nominal') return fam;
  return block.candidates.length === 1 ? first.case : `?${first.case}`;
}

export function autoSort(order, blocks) {
  const byIndex = new Map(blocks.map((b) => [b.token.index, b]));
  const rank = (index) => {
    const key = sortKey(byIndex.get(index)).replace(/^\?/, '');
    return GROUP_RANK[key] ?? GROUP_RANK.unknown;
  };
  return [...order].sort((a, b) => rank(a) - rank(b) || a - b);
}
```

```js
/** FNV-1a, 32-bit, as 8 hex digits. */
export function textHash(text) {
  let h = 0x811c9dc5;
  for (let i = 0; i < text.length; i += 1) {
    h ^= text.charCodeAt(i);
    h = Math.imul(h, 0x01000193) >>> 0;
  }
  return h.toString(16).padStart(8, '0');
}

/**
 * Debounced writer over an injected storage. A storage that throws (private
 * window, quota) turns persistence off silently: the reader still reads.
 */
export function createAutosave({ storage, key, delay = 300, schedule = setTimeout, cancel = clearTimeout }) {
  let timer = null;
  let latest = null;

  function write() {
    timer = null;
    if (latest === null) return;
    try { storage.setItem(key, JSON.stringify(latest)); } catch { /* persistence off */ }
    latest = null;
  }

  return {
    save(obj) {
      latest = obj;
      if (timer !== null) cancel(timer);
      timer = schedule(write, delay);
      if (timer === undefined) write();
    },
    flush() { if (timer !== null) cancel(timer); write(); },
    pending() { return latest !== null; },
    loaded() {
      try {
        const raw = storage.getItem(key);
        return raw ? JSON.parse(raw) : null;
      } catch {
        return null;
      }
    },
  };
}

/** A saved object is applied only to the exact text it was saved for. */
export function restore(saved, text) {
  if (!saved || typeof saved !== 'object' || saved.text !== text) return null;
  return saved;
}
```

Note on the throwing-storage test: `schedule` there calls `write()` synchronously, which runs before `timer` is assigned, so `pending()` is false afterwards — the implementation above handles that because `write()` clears `latest`.

```js
import { describeAnalysis } from './colors.js';

export function toJSON(reader) {
  return JSON.stringify({ version: 1, exported: new Date().toISOString(), ...reader.toJSON() }, null, 2);
}

function line(block) {
  const readings = block.candidates.map((c) => describeAnalysis(c.analysis)).join(' / ') || 'not in lexicon';
  const mark = block.pinned ? ' (pinned)' : block.candidates.length > 1 ? ' (?)' : '';
  return `- ${block.token.surface} — ${readings}${mark}`;
}

export function toMarkdown(reader) {
  const keep = reader.selected;
  const out = [`# Casus — ${new Date().toISOString().slice(0, 10)}`, ''];
  reader.sentences.forEach((sentence, i) => {
    reader.select(i);
    const byIndex = new Map(reader.blocks.map((b) => [b.token.index, b]));
    out.push(`## ${i + 1}. ${sentence.text}`, '');
    for (const index of reader.order) out.push(line(byIndex.get(index)));
    out.push('');
  });
  reader.select(keep);
  return out.join('\n');
}
```

```svelte
<script>
  import { createLexicon } from '../lib/lexicon.js';
  import { makeFetchShard, loadManifest } from './lib/fetchers.js';
  import { createReader } from './stores/reader.svelte.js';
  import { textHash, createAutosave, restore } from './lib/persist.js';
  import TextPane from './components/TextPane.svelte';
  import BlockPane from './components/BlockPane.svelte';
  import Dictionary from './components/Dictionary.svelte';
  import Toolbar from './components/Toolbar.svelte';
  import PassagePicker from './components/PassagePicker.svelte';

  // injected for tests; the browser gets the real ones
  let {
    fetchImpl = (...a) => window.fetch(...a),
    storage = typeof localStorage !== 'undefined' ? localStorage : null,
    schedule = (fn, ms) => setTimeout(fn, ms),
    cancel = (t) => clearTimeout(t),
  } = $props();

  let status = $state('loading the lexicon…');
  let lexicon = $state(null);
  let samples = $state([]);
  let reader = $state(null);
  let autosave = null;
  let hovered = $state(null);
  let open = $state(null);          // the block whose dictionary is open

  $effect(() => {
    loadManifest(fetchImpl)
      .then((manifest) => {
        lexicon = createLexicon({ fetchShard: makeFetchShard(fetchImpl), manifest });
        status = `lexicon ready: ${Object.keys(manifest.shards).length} shards, built ${manifest.built}`;
      })
      .catch((e) => { status = `no lexicon: ${e.message} — run python3 tools/build_index.py`; });
    fetchImpl('/samples/index.json').then((r) => (r.ok ? r.json() : [])).then((list) => { samples = list; }).catch(() => {});
  });

  async function choose(text, era) {
    if (!lexicon) return;
    const key = `casus:${textHash(text)}`;
    autosave = createAutosave({ storage: storage ?? { getItem: () => null, setItem: () => {} }, key, schedule, cancel });
    const saved = restore(autosave.loaded(), text);
    const r = createReader({ lexicon, text, saved });
    if (!saved && era) r.era = era;
    await r.load();
    reader = r;
    open = null;
    r.loadExtras(fetchImpl).catch(() => {});
  }

  // every change is written, debounced; the guard is only armed while a write is pending (§9)
  $effect(() => {
    if (!reader || !autosave) return;
    autosave.save(reader.toJSON());
  });
  $effect(() => {
    if (typeof window === 'undefined') return;
    const guard = (e) => { if (autosave?.pending()) { e.preventDefault(); e.returnValue = ''; } };
    window.addEventListener('beforeunload', guard);
    return () => window.removeEventListener('beforeunload', guard);
  });

  function download(kind, text) {
    const blob = new Blob([text], { type: kind === 'json' ? 'application/json' : 'text/markdown' });
    const a = document.createElement('a');
    a.href = URL.createObjectURL(blob);
    a.download = `casus-${textHash(reader.text)}.${kind === 'json' ? 'json' : 'md'}`;
    a.click();
    URL.revokeObjectURL(a.href);
  }

  const lemmaOf = (id) => reader?.lexiconExtras.lemmas?.[String(id)] ?? null;
</script>

<main>
  <header>
    <h1>Casus</h1>
    <p class="status">{status}</p>
    <PassagePicker {samples} onchoose={choose} {fetchImpl} />
  </header>

  {#if reader}
    <Toolbar {reader} onexport={download} />
    <div class="panes">
      <section class="left"><TextPane {reader} {hovered} /></section>
      <section class="right">
        <BlockPane {reader} onhover={(i) => (hovered = i)} onopen={(b) => (open = b)} {lemmaOf} />
        {#if open}
          {@const current = reader.blocks.find((b) => b.token.index === open.token.index) ?? open}
          <Dictionary block={current} {reader} onclose={() => (open = null)} />
        {/if}
      </section>
    </div>
  {/if}
</main>

<style>
  main { font-family: system-ui, sans-serif; max-width: 1280px; margin: 0 auto; padding: 16px; }

  .left { border-right: 1px solid #ddd; padding-right: 16px; }
</style>
```
