### Method (worked for de and mk)

1. List the language's inventory points per level. A point counts as covered only when a lesson **explains** it
   (a word in an example does not count). Search all of that language's Learn, not only the main path — my first
   German claim ("no numbers") was wrong because the checker looks only at core topics.
2. Write the report `docs/learn/AUDIT-<code>-<date>.md`: missing → new lesson, covered list, and what the audit did not check.
3. Write missing lessons in `tools/curricula/<code>/<level>.yml` (AI-written, marked; en + pt in the file, and overlays
   in `tools/curricula/<code>/i18n/<ui>.*.yml` for the other interface languages the course already has — de course:
   mk, ar; mk course: de, ar). Quote example rows in YAML (`["…?", "…"]`) — a `?` breaks unquoted flow lists.
4. Back up `data/<code>/learn` + `learn.json`, then splice:
   - a level written only by us: `python3 tools/learn_add_written.py <code> A1 A2` (uvx --with pyyaml --with markdown)
   - a level that is already built: `… <code> A1 A2 --only=<new ids>` (never rewrite existing lessons)
   Then `node tools/learn_curriculum.mjs <code> <new,ids>` (Tatoeba exercises, only those lessons), then
   `node tools/check_learn_words.mjs <code>` (look at the new lessons' lines only).
5. Check nothing else changed: `diff -rq backup/learn data/<code>/learn`.
6. Before `bash tools/release_data.sh <code>`: download the published `data-<code>-*.tar.gz`, diff it with local.
   Only the additions may differ; local files that were never released must be moved aside for the upload
   (data/mk has unreleased `ipa-forms/`, `ipa-rules.json` — moved aside today, then put back).
7. Commit + push; deploy = push main + `gh workflow run pages.yml --repo allan-valin/casus-asia` (and `casus-world`).
