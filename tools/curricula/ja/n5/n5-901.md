# Numbers - 数

**Meaning** · counting from one to a hundred million - and the readings that change on the way

Japanese numbers are built like a sum: {f|二十三|にじゅうさん} is "two ten three", {f|四百五|よんひゃくご} is
"four hundred five". Three things need learning by heart: which reading 4, 7 and 9 take, the sound changes in the
hundreds and thousands, and the fact that big numbers are grouped by ten thousand ({f|万|まん}), not by thousand.

## Formation

| Number | Reading | Note |
|---|---|---|
| 0 | ゼロ・れい | ゼロ in speech, れい in announcements and scores |
| 1 – 3 | いち・に・さん | |
| 4 | よん (し) | よん for counting; し only in set words: {f|四月|しがつ} |
| 5 – 6 | ご・ろく | |
| 7 | なな (しち) | なな for counting; しち in {f|七月|しちがつ}, {f|七時|しちじ} |
| 8 | はち | |
| 9 | きゅう (く) | きゅう for counting; く in {f|九月|くがつ}, {f|九時|くじ} |
| 10 | じゅう | |
| 11, 20, 35 | じゅういち・にじゅう・さんじゅうご | tens first, then units |

| Hundreds | | Thousands | |
|---|---|---|---|
| 100 | ひゃく | 1,000 | せん |
| 300 | さん<b>びゃく</b> | 3,000 | さん<b>ぜん</b> |
| 600 | ろっ<b>ぴゃく</b> | 8,000 | はっ<b>せん</b> |
| 800 | はっ<b>ぴゃく</b> | | |

| Big numbers | Reading | Literally |
|---|---|---|
| 10,000 | いちまん | one {f|万|まん} - the いち is never left out |
| 100,000 | じゅうまん | ten {f|万|まん} |
| 1,000,000 | ひゃくまん | a hundred {f|万|まん} |
| 10,000,000 | いっせんまん | a thousand {f|万|まん} |
| 100,000,000 | いちおく | one {f|億|おく} |

To read a big number, split it into groups of four from the right: 1,2345,6789 →
{f|一億|いちおく} {f|二千三百四十五万|にせんさんびゃくよんじゅうごまん} {f|六千七百八十九|ろくせんななひゃくはちじゅうきゅう}.

## Examples

<pre>
このかばんは<b>{f|三千|さんぜん}</b>{f|円|えん}です。
This bag is 3,000 yen.
</pre>

<pre>
{f|家賃|やちん}は<b>{f|八万|はちまん}</b>{f|円|えん}です。
The rent is 80,000 yen.
</pre>

<pre>
{f|部屋|へや}の{f|番号|ばんごう}は<b>{f|八百六|はっぴゃくろく}</b>です。
The room number is 806.
</pre>

<pre>
<b>{f|一万|いちまん}</b>{f|円|えん}{f|札|さつ}しかありません。
I only have a 10,000-yen note.
</pre>

<pre>
{f|東京|とうきょう}には<b>{f|千四百万|せんよんひゃくまん}</b>{f|人|にん}ぐらい{f|住|す}んでいます。
About fourteen million people live in Tokyo.
</pre>

## Nuance & register

On their own, numbers are rarely used to count things: you add a counter (next lesson). The readings above are
the ones for prices, phone numbers, room numbers and plain arithmetic. Phone numbers are read digit by digit, with
の between the groups: 03-1234 → ゼロさんのいちにさんよん.

Written Japanese uses Arabic numerals far more than kanji (3,000円); kanji numerals appear in vertical text, in
set words and in this course's examples, so that you see the readings.

## Common mistakes

- ✗ まん{f|円|えん} for 10,000 yen → ✓ いちまん{f|円|えん}. With {f|百|ひゃく} and {f|千|せん} the "one" is left
  out, with {f|万|まん} and {f|億|おく} it never is.
- ✗ じゅうせん for 10,000 → ✓ いちまん. There is no "ten thousand" built from {f|千|せん}: once you reach four
  zeros, count in {f|万|まん}.
- ✗ さんひゃく → ✓ さんびゃく; ✗ ろくひゃく → ✓ ろっぴゃく.

## Practice

**1.** 300 is read さん___.

<details><summary>Answer</summary>
びゃく - さんびゃく. 300, 600 and 800 change the sound of ひゃく.
</details>

**2.** How do you say 10,000?

<details><summary>Answer</summary>
いちまん - the いち is never dropped before {f|万|まん}.
</details>

**3.** Read 1,500,000.

<details><summary>Answer</summary>
ひゃくごじゅうまん - 150 groups of ten thousand.
</details>
