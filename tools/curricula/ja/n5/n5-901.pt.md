# Numbers - 数

**Meaning** · contar de um a cem milhões - e as leituras que mudam no caminho

Os números japoneses se montam como uma soma: {f|二十三|にじゅうさん} é "dois dez três", {f|四百五|よんひゃくご} é
"quatro cem cinco". Três coisas precisam ser decoradas: que leitura o 4, o 7 e o 9 usam, as mudanças de som nas
centenas e nos milhares, e o fato de que os números grandes se agrupam de dez mil em dez mil ({f|万|まん}), não de mil
em mil.

## Formação

| Número | Leitura | Observação |
|---|---|---|
| 0 | ゼロ・れい | ゼロ na fala, れい em avisos e placares |
| 1 – 3 | いち・に・さん | |
| 4 | よん (し) | よん para contar; し só em palavras fixas: {f|四月|しがつ} |
| 5 – 6 | ご・ろく | |
| 7 | なな (しち) | なな para contar; しち em {f|七月|しちがつ}, {f|七時|しちじ} |
| 8 | はち | |
| 9 | きゅう (く) | きゅう para contar; く em {f|九月|くがつ}, {f|九時|くじ} |
| 10 | じゅう | |
| 11, 20, 35 | じゅういち・にじゅう・さんじゅうご | primeiro as dezenas, depois as unidades |

| Centenas | | Milhares | |
|---|---|---|---|
| 100 | ひゃく | 1.000 | せん |
| 300 | さん<b>びゃく</b> | 3.000 | さん<b>ぜん</b> |
| 600 | ろっ<b>ぴゃく</b> | 8.000 | はっ<b>せん</b> |
| 800 | はっ<b>ぴゃく</b> | | |

| Números grandes | Leitura | Literalmente |
|---|---|---|
| 10.000 | いちまん | um {f|万|まん} - o いち nunca cai |
| 100.000 | じゅうまん | dez {f|万|まん} |
| 1.000.000 | ひゃくまん | cem {f|万|まん} |
| 10.000.000 | いっせんまん | mil {f|万|まん} |
| 100.000.000 | いちおく | um {f|億|おく} |

Para ler um número grande, separe-o em grupos de quatro algarismos a partir da direita: 1,2345,6789 →
{f|一億|いちおく} {f|二千三百四十五万|にせんさんびゃくよんじゅうごまん} {f|六千七百八十九|ろくせんななひゃくはちじゅうきゅう}.

## Nuance e registro

Sozinhos, os números quase nunca contam coisas: junta-se um contador (próxima lição). As leituras acima são as de
preços, telefones, números de quarto e contas. O telefone se lê algarismo por algarismo, com の entre os grupos:
03-1234 → ゼロさんのいちにさんよん.

O japonês escrito usa muito mais algarismos arábicos que kanji (3,000円); os numerais em kanji aparecem no texto
vertical, em palavras fixas e nos exemplos deste curso, para você ver as leituras.

## Erros comuns

- ✗ まん{f|円|えん} para 10.000 ienes → ✓ いちまん{f|円|えん}. Com {f|百|ひゃく} e {f|千|せん} o "um" cai; com
  {f|万|まん} e {f|億|おく}, nunca.
- ✗ じゅうせん para 10.000 → ✓ いちまん. Não existe "dez mil" feito com {f|千|せん}: chegando a quatro zeros, conte
  em {f|万|まん}.
- ✗ さんひゃく → ✓ さんびゃく; ✗ ろくひゃく → ✓ ろっぴゃく.
